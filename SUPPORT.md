# Support

Use [GitHub Issues](https://github.com/antibagr/tbc-insurance-mcp/issues) for
reproducible software bugs and focused feature proposals. Search existing issues
first and include the server version, operating system, MCP host, sanitized
error code, and a synthetic reproduction.

Public issues must contain no credentials, names, policy or claim references,
personal numbers, contact details, medical information, appointment details,
portal screenshots, authenticated responses, or debug logs from a real account.
Use the process in [SECURITY.md](SECURITY.md) for vulnerabilities.

The project cannot resolve insurer account access, policy interpretation,
coverage, reimbursement, claims, referrals, payments, or appointment
availability. Use the
[official TBC Insurance contact page](https://tbcinsurance.ge/en/contact) for
those matters.

This volunteer project offers no response-time or compatibility guarantee.
